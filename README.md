# VPN SaaS Platform

A VPN reseller system with:

- Admin dashboard (Next.js)
- Backend API (Node.js + Express)
- Database (Supabase)
- VPN key management (Outline)

## Features

- Manage customers
- Create orders
- Assign VPN keys
- Track plans and usage

## Tech Stack

- Next.js
- Node.js / Express
- Supabase
- Outline VPN
