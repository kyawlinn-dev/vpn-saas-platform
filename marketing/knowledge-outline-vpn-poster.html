#NovaNet-MM
1
Key တစ်ခု = VPN Access တစ်ခု
Outline App ထဲထည့်လိုက်တာနဲ့ VPN server ကို connect လုပ်နိုင်ပါတယ်။
2
App က Outline ဖြစ်ရမယ်
Key ကို copy/paste မလုပ်ဘဲ “Add Key To Outline” ခလုတ်နဲ့ တန်းထည့်နိုင်ပါတယ်။
3
Data Limit ပါနိုင်တယ်
Plan အလိုက် 50GB / 100GB စသဖြင့် data usage ကို system ထဲမှာစစ်နိုင်ပါတယ်။
4
Server ပြောင်းလို့ရတယ်
Connection အဆင်မပြေရင် Singapore / India စတဲ့ server ကိုပြောင်းစမ်းနိုင်ပါတယ်။
Tip: Key ကို public comment ထဲ မတင်ပါနဲ့။ ကိုယ့် key ကို ကိုယ်ပဲသုံးပါ။
