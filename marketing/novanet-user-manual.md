# NovaNet MM VPN User Manual

## NovaNet MM VPN အသုံးပြုနည်း

NovaNet MM VPN သည် Telegram Bot + Mini App မှတစ်ဆင့် Outline VPN key ကို 24/7 ကိုယ်တိုင်ဝယ်ယူ၊ key ရယူ၊ data usage စစ်၊ server ပြောင်းနိုင်သော VPN service ဖြစ်ပါသည်။

---

## 1. Telegram Bot ကိုစတင်အသုံးပြုနည်း

1. TikTok bio / share link ထဲမှ NovaNet MM VPN Telegram Bot ကိုဖွင့်ပါ။
2. Telegram ထဲတွင် **Start** ခလုတ်ကိုနှိပ်ပါ။
3. Bot menu တွင် အောက်ပါ option များကိုတွေ့ရပါမည်။
   - Outline Key ရယူရန်
   - လက်ကျန် GB စစ်ရန်
   - Server ပြောင်းရန်
   - Package ဝယ်ရန်
   - Admin / Support

---

## 2. New User 5GB Free Trial ယူနည်း

New user များအတွက် **5GB / 7 Days Free Trial** ရရှိနိုင်ပါသည်။

1. Telegram Bot ကိုဖွင့်ပါ။
2. **Start** နှိပ်ပါ။
3. Bot menu ထဲမှ trial / key option ကိုရွေးပါ။
4. System မှ Outline VPN key ကိုပေးပါမည်။
5. **Add Key To Outline** ခလုတ်ကိုနှိပ်ပြီး Outline app ထဲသို့ထည့်ပါ။

မှတ်ချက်: Free trial သည် account အသစ်များအတွက်သာ ရရှိနိုင်ပါသည်။

---

## 3. Outline App ထဲ Key ထည့်နည်း

1. ဖုန်းတွင် **Outline** app ကို install လုပ်ထားပါ။
2. Telegram Bot မှပေးသော key message ထဲတွင် **Add Key To Outline** ကိုနှိပ်ပါ။
3. Outline app ပွင့်လာပါက key ကို accept / add လုပ်ပါ။
4. Server ပေါ်လာပြီးပါက **Connect** နှိပ်ပါ။
5. VPN စတင်အသုံးပြုနိုင်ပါပြီ။

အကယ်၍ button မနှိပ်နိုင်ပါက `ssconf://...` ဖြင့်စသော key link ကို copy လုပ်ပြီး Outline app ထဲတွင် manually add လုပ်နိုင်ပါသည်။

---

## 4. Package ဝယ်ယူနည်း

1. Telegram Bot ထဲမှ **Open** ခလုတ်ဖြင့် Mini App ကိုဖွင့်ပါ။
2. အောက်ခြေ menu မှ **Packages** ကိုရွေးပါ။
3. သင်ဝယ်လိုသော plan ကိုရွေးပါ။
   - Basic: 50GB / 30 Days
   - Premium: 100GB / 30 Days
4. **Buy Now** ကိုနှိပ်ပါ။
5. Payment page သို့ရောက်ပါမည်။

---

## 5. KBZPay ဖြင့် Payment တင်နည်း

1. Payment page တွင်ပြထားသော KBZPay account သို့ ငွေလွှဲပါ။
2. Amount ကို plan price အတိုင်း အတိအကျလွှဲပါ။
3. ငွေလွှဲပြီးပါက payment screenshot ကို save လုပ်ပါ။
4. Mini App ထဲတွင် **Upload payment screenshot** ကိုနှိပ်ပါ။
5. Screenshot ကိုရွေးပြီး upload လုပ်ပါ။
6. Payment note ရေးလိုပါက optional note ထည့်ပါ။
7. **Submit Payment** ကိုနှိပ်ပါ။

Admin မှ payment ကိုစစ်ပြီး approve လုပ်ပြီးပါက Outline key ရရှိပါမည်။

---

## 6. Outline Key ပြန်ယူနည်း

Key ပျောက်သွားခြင်း၊ phone အသစ်တွင်ထည့်လိုခြင်းတို့အတွက် key ကိုပြန်ယူနိုင်ပါသည်။

1. Telegram Bot ကိုဖွင့်ပါ။
2. **Outline Key ရယူရန်** option ကိုနှိပ်ပါ။
3. Bot မှ သင့် account နှင့်ဆိုင်သော key ကိုပြန်ပေးပါမည်။
4. **Add Key To Outline** ကိုနှိပ်ပြီး app ထဲသို့ပြန်ထည့်နိုင်ပါသည်။

---

## 7. လက်ကျန် GB / Data Usage စစ်နည်း

1. Telegram Bot သို့မဟုတ် Mini App ကိုဖွင့်ပါ။
2. **လက်ကျန် GB စစ်ရန်** သို့မဟုတ် Home screen တွင် usage section ကိုကြည့်ပါ။
3. သုံးပြီး data နှင့် စုစုပေါင်း plan data ကိုမြင်နိုင်ပါသည်။

ဥပမာ: `0.0 / 100GB` ဆိုပါက 100GB plan ထဲမှ data မသုံးရသေးပါ။

---

## 8. Server ပြောင်းနည်း

Connection မကောင်းခြင်း၊ speed မတည်ငြိမ်ခြင်းဖြစ်ပါက server ပြောင်းစမ်းနိုင်ပါသည်။

1. Mini App ကိုဖွင့်ပါ။
2. အောက်ခြေ menu မှ **Servers** ကိုရွေးပါ။
3. Available server list ကိုကြည့်ပါ။
4. Singapore / India စသည်ဖြင့် သင့်အတွက်အဆင်ပြေသော server ကိုရွေးပါ။
5. Server ပြောင်းပြီးပါက Outline app ထဲတွင် key ကိုပြန်ဖွင့်ပြီး connect လုပ်ပါ။

---

## 9. အသုံးပြုရာတွင် သတိထားရန်

- ကိုယ့် Outline key ကို public comment ထဲတွင် မတင်ပါနှင့်။
- Key ကိုမသိသောသူများထံ မမျှဝေပါနှင့်။
- Payment screenshot မမှန်ပါက order approve မဖြစ်နိုင်ပါ။
- Amount ကို plan price အတိုင်း အတိအကျလွှဲပါ။
- Trial / paid plan မသုံးမီ Outline app ကို install လုပ်ထားပါ။

---

## 10. အခက်အခဲဖြစ်ပါက Support ကိုဆက်သွယ်ရန်

အောက်ပါအခြေအနေများတွင် Admin / Support ကိုဆက်သွယ်ပါ။

- Payment တင်ပြီး key မရသေးပါ။
- Outline app ထဲ key ထည့်မရပါ။
- Server connect မဖြစ်ပါ။
- Data usage မမှန်ဟုထင်ပါသည်။
- Package ဝယ်ယူရာတွင် error ဖြစ်ပါသည်။

Telegram Bot ထဲမှ **Admin / Support** ကိုနှိပ်ပြီး ဆက်သွယ်နိုင်ပါသည်။

---

## Quick Start Summary

1. Telegram Bot ကိုဖွင့်ပါ။

4. Add Key To Outline နှိပ်ပါ။
5. Outline app ထဲ connect လုပ်ပါ။
6. အဆင်ပြေပါက Mini App ထဲမှ package ဝယ်ပါ။
